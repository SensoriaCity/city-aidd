# Bitácora del piloto

Una entrada por squad cada viernes. Se agrega al final, no se edita lo anterior. Los tropiezos son la materia prima para cambiar el kit: una skill o regla nueva entra solo si el mismo tropiezo aparece dos veces.

Plantilla:

```
## Semana <n> · <AAAA-MM-DD> · <squad> · kit <versión>
- PRs abiertos / mergeados: <n> / <n>
- Tamaño p50 / p85: <líneas> / <líneas>
- % mergeado sin revisión humana: <%>
- Primera revisión humana p50: <horas> · % aprobación rápida: <%>
- QA en navegador: <cortes probados> · hallazgos altos reales / ruido: <n> / <n> · BLOQUEADO por entorno: <n> · tiempo típico: <min>
- QA humano de features completas: <features probadas> · hallazgos que el agente debió ver: <n y enlace>
- Tropiezos: <qué pasó, en qué skill o paso, enlace al PR o sesión>
- Trabajo que no cupo en AIDD Lite: <qué y por qué, o "ninguno">
- Propuesta de cambio al kit: <una, o "ninguna">
```
